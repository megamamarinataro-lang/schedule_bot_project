# Google Sheets Schedule Bot Engine

Консольное приложение на Python для автоматизированного извлечения расписания занятий из облачной таблицы Google Таблиц в реальном времени.

## Функционал
* **Интеграция с API:** Взаимодействие с Google Sheets API с помощью библиотеки `gspread`.
* **Авторизация:** Безопасный доступ через JSON-ключ сервисного аккаунта (`credentials.json`).
* **Динамический парсинг:** Чтение данных по именам полей без жёсткой привязки к индексам столбцов.
* **Кэширование (TTL):** Встроенный кэш в памяти на 300 секунд (5 минут) для снижения нагрузки на API и ускорения ответов.
* **Служебное логирование:** Вывод в консоль даты, времени и статуса обновления кэша.

## Запуск
1. Установите зависимости:
   ```text
   python -m pip install gspread
   ```
2. Разместите файл ключа `credentials.json` в корневой папке проекта.
3. Убедитесь, что для почты сервисного аккаунта открыт доступ к Google Таблице "Schedule_2026".
4. Запустите скрипт:
   ```text
   python schedule_bot.py
   ```
